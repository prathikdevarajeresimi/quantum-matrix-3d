# 🔮 Quantum Matrix 3D — WebGL Particle Universe

An interactive 3D particle universe capable of morphing between high-dimensional geometric structures (Spheres, Toruses, and Cosmic Waves) rendered at smooth 60 FPS using **Three.js** & **WebGL**.

![WebGL](https://img.shields.io/badge/WebGL-Three.js-00f0ff?style=for-the-badge&logo=three.js)
![License](https://img.shields.io/badge/License-MIT-ff007f?style=for-the-badge)

## ✨ Features
- **7,000 Real-Time Particles**: Physics simulation powered by GPU shaders.
- **Morphing Geometries**: Smooth interpolation between Quantum Sphere, Hyper Torus, and Cosmic Wave.
- **Interactive Mouse Physics**: Gravitational rotation driven by mouse and cursor tracking.
- **Additive Blending**: Glowing neon gradient colors with zero frame drops.

## 🕹️ Controls
- **Mouse Movement**: Rotate the particle space.
- **Shape Buttons**: Morph into different mathematical dimensions.
- **Scroll**: Zoom in and out.
